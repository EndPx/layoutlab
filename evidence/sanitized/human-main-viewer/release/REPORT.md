# Main human release integration

## Implementation

Completed the shared source-normalized frame for the main viewer: source forward -Z receives shared PI then authoritative engine heading. The whole worker/cart/tote assembly uses this yaw. Pooled carried cartons rotate their already-normalized dock/cell offsets and cargo yaw identically; engine x/z anchors do not change. Selected crate labels use the same rotation. Cargo helper tests preserve relative coordinates, scale and height at 90/180/270 degrees. Historical zero-yaw tests keep their assertions. World-axis AABBs intentionally rotate while source SKU dimensions remain unchanged.

Absolute heading remains the last completed nonzero segment heading during waits. Initial/no-history carts retain historical canonical orientation. Archived snapshots without timed segments use explicitly disclosed stable worker animation rather than guessed accumulated distance. Heading changes are instantaneous, with no renderer turn timing, path planning or inventory actions. Traffic uses cart footprints; human-body reservations, turning sweeps and calibrated kinetics remain unqualified.

Lifecycle corrections clear old human errors on mount/success, show source failure while carts remain available, retry rejected model loads on a later scene, and remove an attached rig frame before disposing its skeleton on bind failure. Source GLTF geometry/material cache stays shared. Motion history is grouped once per update instead of scanned twice per worker. Fixed-size actual joint pose diagnostics remain available. Measured CPU timing covers sampling, yaw placement, skeleton application and diagnostic serialization, not GPU work or FPS.

Bake reproduction is self-contained in versioned production inputs: `node apps/web/src/lib/humanBake.mjs` from root uses humanBakeDriver.mjs, frozen workwear-v2 glTF and main-pose-v1.json, and emits main-gait-v1.json with source/pose/driver hashes. The copied offline finite driver is never imported by browser runtime. No .coordination browser URL, geometry dump, solver or evaluation log is shipped.
