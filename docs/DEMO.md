# Demo: inspect, change, compare, verify

**[Watch the 2m20 demo](https://youtu.be/webE5e5WNbo)**

Open [LayoutLab](https://layoutlab.endpx.cloud), or start the [native runtime](LOCAL_RUNTIME.md). The unified Operations workspace uses synthetic data. Sample/manual controls, recorded examples and verification need no key. Live Gater inference is enabled without username/password. Recorded examples preserve earlier runs and remain separately labeled.

1. **Establish the baseline.** Run the six-order picking and packing sample and inspect workers, stations and orders. Elapsed time, shipped count and combined waiting are different metrics: summed waiting can exceed elapsed time. Visible workers are cart-based units.
2. **Inspect the recorded decision.** The historical service-duration investigation made three Meta requests. Baseline makespan is 502,400 ms; a selected 30-second dispatch assumption yields 397,100 ms. This is a hypothetical synthetic experiment, not observed facility savings or a physical-layout improvement. Reviewing it makes no new model request.
3. **Test a physical alternative.** In Physical layout, run the baseline, edit a supported rack/station translation, rack quarter-turn or existing-unit initial parking, then validate and test. Compare original and proposed measurements. Candidates retain separate initial conditions and the original comparison. Worse results remain visible. Apply a compatible tested layout or discard the draft.
4. **Export the decision.** Export the exact comparison and use its matching recompute control. Recorded service-duration results also expose export and verification. Recalculation uses saved inputs without inference; scene changes do not rewrite historical report inputs. See the [judge guide](JUDGES_GUIDE.md) for terminal commands.

Manual controls and model proposals have different scopes: bounded packing-station assistant evidence does not establish model rack-rotation capability. Model suggestions are proposals; deterministic validators and the engine own measurements. Historical Meta runs, replay, stubs and local Gater fixtures are distinct. Public GLM packing-station interpretation, approval, engine evaluation and model finish are verified on one controlled sample. No real-facility validation, integrated human-body traffic physics, global optimality or universal superiority is claimed. See [asset provenance](ASSET_PROVENANCE.md).
